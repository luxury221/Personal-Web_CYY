01 / RETRIEVAL & GROUNDING

Multimodal RAG

当答案分散在文本、表格、图片与跨页关系中时，系统怎样检索并组织一条真正可验证的证据链？

REPRESENTATION结构化证据节点

保留 page / bbox / section / figure / caption / table，而不是把文档压成无结构文本块。

RETRIEVAL混合召回与图传播

Embedding、BM25、视觉、表格、KG 与 reference routes 共同提供候选，并使用图关系寻找 bridge evidence。

VERIFICATION证据链自修正

不让 reranker 的单一高分替代完整证据；检查模态覆盖、链完整度与回答句子的支持度。

PROOF / MULTIRANK-RAG

FinQA nDCG@5：0.678 → 0.878；MultiHop-RAG V5 evidence-chain score：0.890。下一步重点是提升 MMLongBench-Doc 的绝对视觉召回能力。

02 / PLANNING & CONTROL

Agentic Systems

怎样让 Agent 会计划、会用工具、会记忆，但不会因为“自由发挥”而失去可控性与可解释性？

ORCHESTRATION显式状态机与角色边界

把任务拆成职责清晰的角色，用结构化 artifact 交接，而不是让多个 Agent 无约束互聊。

MEMORY长期状态而非聊天历史

保存用户偏好、证据、任务完成状态和反馈，并区分预测状态与被新证据验证后的实证状态。

GUARDRAIL证据 Gate 与确定性评分

关键判断不交给大模型自由生成：评分规则、能力维度、证据要求和下一动作都显式化。

PROOF / KONGMING

六类 Agent 围绕共享上下文协作；500 条岗位保留来源与内容哈希；十余个 verify 脚本覆盖面试评分、成长闭环与完整用户流程。

03 / ROBUSTNESS & INTERPRETABILITY

Evaluation & Interpretability

如果模型输出看起来更好，我们应该用什么证据证明改进来自方法本身，而不是数据、候选集或随机性？

ABLATION固定候选集的消融

保持 retriever 与 candidate K 不变，再逐层加入结构、视觉、GraphRAG、rerank 与 evidence guard。

ROBUSTNESS不确定性与表征探针

用线性探针和 token 分布不确定性特征预测模型在问题上的鲁棒性，而不是只看最终答案。

REPRODUCIBILITY离线可复现评测

固定模型缓存、运行时版本、网络与输入输出约束，保证提交结果在同一容器中可以复现。

PROOF / ABLATION + AIMO

MultiRank-RAG 保留公开 V0–V5 benchmark；AIMO Interpretability 方向尝试线性 probe 与 14 项不确定性统计，用离线 GPU 容器验证鲁棒性预测。

04 / REALTIME INTERACTION

Multimodal Interaction

当语言模型进入语音、视觉、3D 与实时交互环境后，系统如何处理时序、中断、状态与多模态输入之间的协同？

REALTIME双向语音流

WebSocket 承载实时语音与会话状态，必须处理打断、结束、重连与延迟。

SPATIAL3D 场景与动作

Three.js / React Three Fiber 将模型输出映射到可观察的空间和角色动作，而不只是文本 UI。

MULTIMODAL手势与语音协同

MediaPipe 的视觉事件和语音对话共同改变实时状态，为更复杂的 embodied / agent interaction 打基础。

PROOF / INTERACTIVE AVATAR

文本/图片/预设生成 3D 角色 → 辅助绑骨 → 场景配置 → Qwen 实时语音 + MediaPipe 手势 → 会话历史与录屏，完整跑通多模态交互闭环。
