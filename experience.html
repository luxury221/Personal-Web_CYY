01 / STRUCTURED RETRIEVAL

MinerU / 本地解析保留页码、bbox、阅读顺序与版面关系；文本、标题、表格、图片、图注和公式统一进入 evidence node schema，再建立 structure / reference / entity / semantic edges。

02 / ADAPTIVE RERANK

Query Planner 根据文本、表格、视觉与跨模态桥接问题改变召回路线；G0–G4 逐层加入语义、图传播、bridge evidence、reference matching、visual grounding 与证据链约束，并用 primary / fallback / merge verifier 做证据自修正。

03 / EVALUATION

公开 V0–V5 消融覆盖 RAGBench eManual、FinQA、MMLongBench-Doc 与 MultiHop-RAG。简单文本任务用作负对照，结构化、多跳和多模态任务用于验证新增模块的真实贡献，而不是只展示单次 Demo。

01 / JOB KNOWLEDGE RAG

岗位库保留官方来源、抓取时间与内容哈希；LlamaIndex 编排索引，Qdrant 与 BM25 并行召回并可接 CrossEncoder 二阶段重排，让匹配结论能够回链原始 JD。

02 / EVIDENCE-BASED DECISION

简历解析优先 PDF.js，必要时回退 RapidOCR / 视觉模型；能力、经历、关键词、意向与成长潜力五维评分都绑定岗位依据和简历证据，面试追问根据上一轮证据选择澄清、深挖或换维度。

03 / MEMORY & GROWTH LOOP

长期记忆保存偏好、会话与反馈；成长系统把预测分和实证分拆开，只有新简历解析或新面试完成后才更新实证状态，避免“勾选任务就涨分”的伪成长。

01 / CONTROLLED GRADING

AI 只输出建议评分和依据，最终成绩由教师确认；发布时固定评分细则快照，降低不同批次、不同助教和模型变化导致的评分漂移，并保留全过程记录用于复盘。

02 / ASYNC & STORAGE

默认 8 路 AI Worker 共享 Redis 队列并行消费；MinIO 负责私有对象存储与签名 URL，API / Auth / Worker 分离，既能单机部署也能拆成公网边缘机与内网业务机。

03 / CODE EXECUTION & DEPLOYMENT

代码题通过 Theia 工作区与 Judge0 执行链路隔离运行环境，生产变量从统一配置生成，Docker Compose 固化依赖与服务边界，使“AI 功能”能够作为真正的平台能力而不是单次接口调用。

01 / AVATAR PIPELINE

文本、图片、预设三入口进入 Meshy 生成，再通过 8 点位标注、任务轮询与动作预览完成辅助绑骨，把复杂的 3D 流程收敛成普通用户可操作的四步工作流。

02 / REALTIME SESSION

Qwen 实时语音、ASR 与 WebSocket 构成双向会话链路，支持打断和自动结束；MediaPipe 识别挥手等手势触发 3D 动作，使语言模型开始进入视觉、空间和实时交互环境。

03 / DATA LOOP

FastAPI、SQLAlchemy 与 Alembic 管理用户、模型和会话，Dashboard 汇总模型记录、会话事件、摘要与录屏，使一次实时交互变成可查询、可复盘的数据资产。
