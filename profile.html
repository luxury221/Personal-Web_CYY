01 / EVIDENCE

证据如何进入系统

在文本、表格、图片和跨页结构中保留来源与关系，让生成结果能够回到可检查的 evidence。

02 / CONTROL

推理如何被约束

通过显式状态、角色边界、工具协议与证据 Gate，减少 Agent 在关键决策中的自由漂移。

03 / EVALUATION

改进如何被证明

固定候选、设置负对照、做逐层消融并保留失败案例，让“更复杂”只有在实验支持时才被称为“更好”。

WORKING PRINCIPLES

我如何做 AI 系谊

01 / EVIDENCE

Evidence First

先确认依据是否足够，再生成结论；答案、评分和 Agent 决策应尽量回到具体来源，而不是只给出“模型认为”。

02 / EVALUATION

Measure the Gain

固定对照条件、做消融、保留失败案例；如果指标不支持改进，就不把额外模块和复杂度包装成创新。

03 / DELIVERY

Ship the System

模型能力必须进入能跑、能测、能部署、能回归的系统；性能、延迟、异步任务、数据边界与 Human-in-the-loop 都是方法的一部分。
